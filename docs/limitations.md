# Scope and Limitations

- The physical rover uses Arduino-based embedded control.
- The ROS 2/Gazebo environment is documented as a simulation environment.
- Do not describe the physical rover as ROS 2 controlled unless a verified ROS 2 hardware interface is added.
- Do not claim SLAM, Nav2, autonomous localization, LiDAR navigation, or AI perception unless corresponding source code and test evidence are added.
- The repository currently documents the project and preserves its media; the original ROS 2 source workspace can be added later without changing the project narrative.
